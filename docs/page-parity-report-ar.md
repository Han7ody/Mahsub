## ب) جرد التحسينات (من الصفحات المرجعية)

### 1. **استخدام الـ Hooks المشتركة**

#### 1.1 usePageLoading Hook
- **الموقع:** `hooks/usePageLoading.ts`
- **مستخدم في:** صفحة الديون، صفحة العمال
- **الوصف:** يدمج حالة التحميل المحلية `isLoading` مع السياق العام `useLoading()` في متغير واحد
- **النمط:** `const showLoading = usePageLoading(isLoading);`
- **الفائدة:** يلغي تكرار نمط `isLoading || globalLoading`

#### 1.2 useEmptyState Hook
- **الموقع:** `hooks/useEmptyState.ts`
- **مستخدم في:** صفحة الديون، صفحة العمال
- **الوصف:** يحدد نوع الحالة الفارغة ("empty", "noResults", أو null)
- **الفائدة:** يلغي منطق حساب الحالة الفارغة يدوياً

#### 1.3 useDebounce Hook
- **الموقع:** `hooks/useDebounce.ts`
- **مستخدم في:** الديون (200ms)، العمال (300ms)
- **الوصف:** يؤخر تنفيذ البحث لمنع الاستدعاءات المفرطة للـ API
- **الفائدة:** تجربة بحث أكثر سلاسة، تقليل استدعاءات API

#### 1.4 useLoadMorePagination Hook
- **الموقع:** `hooks/useLoadMorePagination.ts`
- **مستخدم في:** صفحة الديون
- **الوصف:** يدير ترقيم "تحميل المزيد" مع أحجام صفحات متجاوبة (موبايل: 15، ديسكتوب: 20)
- **الفائدة:** سلوك ترقيم متسق، تحسين الأداء

### 2. **أدوات التنسيق**

#### 2.1 formatCurrencySDG
- **الموقع:** `lib/format.ts`
- **الوصف:** ينسق المبالغ المالية بشكل متسق: `"1,234 SDG"`
- **الفائدة:** تنسيق موحد للعملة في التطبيق

#### 2.2 formatDateLabel
- **الموقع:** `lib/format.ts`
- **الوصف:** ينسق التواريخ مع تسميات سياقية (اليوم، أمس، أو التاريخ)
- **الفائدة:** عرض تواريخ سهل الاستخدام

### 3. **مكون CollapsibleHeader**

- **الموقع:** `components/common/CollapsibleHeader.tsx`
- **مستخدم في:** صفحة الديون، صفحة العمال
- **الوصف:** رأس قابل للطي مرتبط بالتمرير للموبايل مع:
  - رسوم متحركة سلسة للطي عند التمرير (نطاق 60-120px)
  - زر البحث ينتقل من الأسفل إلى حالة مدمجة في الأعلى
  - ديسكتوب: بدون تغييرات (رأس ثابت)
  - موبايل: رأس ديناميكي يتقلص/يتوسع حسب موضع التمرير
- **الفائدة:** تجربة موبايل أفضل، مساحة شاشة أكبر عند التمرير

### 4. **جلب البيانات والتكامل مع الخادم**

#### 4.1 نمط معالجة الأخطاء
- **صفحة العمال:** تعرض لافتة خطأ مع زر إعادة المحاولة
- **الفائدة:** تجربة مستخدم أفضل للأخطاء مع خيار الاستعادة

#### 4.2 نمط التحديثات المتفائلة (Optimistic Updates)
- **صفحة الديون:** تنفذ تحديثات متفائلة لعمليات الإنشاء/التعديل/الحذف
  - إضافة معاملة: تظهر فوراً بمعرف مؤقت، يُستبدل بالمعرف الحقيقي بعد نجاح API
  - تعديل معاملة: تحديث الواجهة فوراً، التراجع عند الخطأ
  - تغذية بصرية: العناصر الجديدة مميزة بـ `border-primary ring-2 ring-primary/30 animate-pulse`
  - إزالة التمييز تلقائياً بعد 3 ثوان
- **الفائدة:** ردود فعل فورية، أداء محسوس أفضل

#### 4.3 تحسين الطلبات الدفعية (Batch Requests)
- **صفحة العمال:** تجلب جميع روابط الصور في طلب دفعي واحد
- **الفائدة:** تقليل استدعاءات API من N إلى 1، تحميل أسرع للصفحة
